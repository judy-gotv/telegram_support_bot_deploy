# APTV Support Bot 功能说明

Telegram 工单机器人（Cloudflare Worker），用户私聊 bot 提交问题 / 申请解封，管理员在私聊中统一处理。

## 环境变量

| 变量 | 必填 | 说明 |
|---|---|---|
| `BOT_TOKEN` | 是 | Bot Token |
| `ADMIN_CHAT_ID` | 是 | 管理员的 Telegram 用户 ID（数字） |
| `TELEGRAM_SECRET_TOKEN` | 否 | Webhook 校验密钥 |
| `SETUP_SECRET` | 否 | `/telegram/setup` 与 `/telegram/status` 接口的访问密钥 |
| `QUNID` | 否 | 绑定的群组 ID（例如 `-1002176362246`），用于 `/unban` 自动解封；不设置则走手动流程 |

## 接口

- `GET /` — 健康检查
- `/telegram/setup?secret=xxx` — 设置 Webhook + 注册命令菜单（`/start` `/send` `/unban` `/help`）
- `/telegram/status?secret=xxx` — 查看 bot 信息与 Webhook 状态
- `POST /telegram/webhook` — Telegram 消息回调（仅处理私聊）

## 用户命令

- `/start` / `/help` — 查看使用说明
- `/send 你的问题` — 提交工单消息（直接发文字不带 `/send` 会被提示用指令发送，防广告轰炸）
- `/unban` — 申请解封 / 解除禁言

## 管理员功能

### 1. 引用回复工单（推荐）

收到「新的工单消息」通知后，**直接引用（Reply）这条通知消息，输入回复内容发送**，bot 会自动从引用消息中解析用户 ID 并把回复发给对方。无需再敲 `/reply 用户ID`。

- 回复会以「技术支持回复：」开头发送给用户
- 发送成功后管理员会收到「已发送（用户ID：xxx）」确认
- 如果引用了非工单消息，bot 会提示重新引用

### 2. 命令回复（兼容旧方式）

- `/reply 用户ID 回复内容` — 以「技术支持回复：」开头回复用户
- `/say 用户ID 消息内容` — 原样发送消息给用户（无前缀）

### 3. `/unban` 自动解封

用户发送 `/unban` 后：

1. 未设置 `QUNID` → 通知管理员手动处理（原流程）
2. 已设置 `QUNID` → bot 先查询该用户在绑定群中的状态：
   - 被封禁（kicked）→ **自动调用解封接口**，用户收到"已自动为你解除封禁"，管理员收到一条"已自动解封"记录，全程无需手动操作
   - 禁言中（restricted）→ 转管理员手动解除禁言
   - 未被封禁 → 告知用户当前没有被封禁，并转管理员确认
   - 查询/解封接口失败 → 转管理员手动处理，并附带失败原因

### 前提条件

- bot 必须是绑定群的**管理员**，且拥有「封禁用户」权限，否则自动解封会因权限不足失败并转手动
- 解封后用户需要自己重新加入群组（bot 不会自动拉人）

## 异常处理

- 处理消息时抛出异常 → 自动通知管理员「机器人处理异常：xxx」
- 给用户/管理员发消息失败 → 给对方返回失败原因，不静默丢弃
